## 更新约定

- 日常改动先检查差异、运行对应测试和敏感信息扫描，再更新各仓库的 `main`；多人或多个 agent 同时修改时使用分支和 PR。
- 原作者的新版本不会自动同步；先查看差异、测试兼容性，再手动合并。
- 插件许可证、原作者和版权声明保留在各插件仓库。
- 运行配置、缓存、凭据和本机验证用的测试文件不发布。

具体流程见 [维护与同步方案](MAINTENANCE.md)，本次检查结果见 [仓库内容与配置审查](AUDIT-2026-10-14.md)。

可复用的本机 GitHub / 部署目录定时检查器位于 [`tools/repo-watch`](tools/repo-watch/README.md)；机器路径配置留在本机。

## 安装

在 AstrBot 插件管理中选择“通过仓库地址安装”，填入表中对应维护仓库 URL。当前机器的 13 个已安装插件均已登记对应维护仓库；通过仓库地址安装的插件后续可从各自的维护仓库更新。
